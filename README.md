### Official Description:
A writing and reading tool that adapts text difficulty in real time. Authors get word-level readability feedback and reader-struggle data as they write; readers can switch between beginner, intermediate, and advanced versions of the same passage, or step through it word-by-word in a "karaoke" mode with instant definitions and context links.
